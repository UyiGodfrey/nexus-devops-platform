## Curation and cleanup policy

1. Keep hands-on work with meaningful code or documented results.
2. Promote a practice project to the featured portfolio only after verifying its README, runnable path and evidence.
3. Avoid duplicate featured entries where several repositories demonstrate the same small skill.
4. Never delete or archive a repository solely because its name looks old.
5. Check for accidentally committed credentials before resharing older repositories.
6. Use a clear README that states the problem, technologies, reproduction steps, evidence and honest limitations.
